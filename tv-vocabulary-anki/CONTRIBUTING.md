# Contributing to TV Episode Anki Deck Generator Skills

Thank you for considering contributing to this repository!

## How Can I Contribute?

### 1. Reporting Bugs / Issues
If you find a prompt hallucination, improper vocabulary filtering, or incorrect German grammatical outputs, please open an Issue with:
- The show name, season, and episode used.
- The unexpected output.
- Suggested prompt corrections.

### 2. Submitting Pull Requests
1. Fork the repository.
2. Create a feature branch (`git checkout -b feature/NewLanguageSkill`).
3. Commit your changes (`git commit -m 'Add French TV episode skill'`).
4. Push to the branch (`git push origin feature/NewLanguageSkill`).
5. Open a Pull Request.

## Formatting Guidelines
- Keep `SKILL.md` compliant with standard YAML frontmatter (`name`, `description`).
- Ensure all example sentences use `<b>target_word</b>` for HTML bolding compatibility in Anki.
